# Terminológia

| Kifejezés | Jelentés | Használat |
|---|---|---|
| Havi lap | a Sheet `YYMM` nevű munkalapja egy hónap cikkeivel (pl. `2609`) | „havi lap”; kerülendő: „munkafüzet” |
| Ügyfél döntése | a havi lap I oszlopa: `Mehet` vagy `LinkedIn poszt` | pontosan ezekkel az értékekkel |
| Mehet | a cikk élesben feltöltendő az xperion.hu-ra | |
| LinkedIn poszt (döntés) | a cikkből LinkedIn-poszt készül | |
| Javaslat | `Erősen javasolt` / `Javasolt` / `Nem javasolt` / `Nem javasolt (már fent)` | a rendszer javaslata, nem döntés |
| Feltöltve | a cikk már fent van (régi lapokon G = „Igen”, újakon J = „Feltöltve”) | |
| Próbaidőszakos forrás | „próbaidőszak” megjegyzésű forrás; cikkei külön blokkba kerülnek | |
| Posztötlet | az ügyfél saját ötlete a „Posztötletek” lapon | |
| Poszt ID | `LI-YYMM-NN` (pl. `LI-2609-01`) | |
| LinkedIn szabályok | a posztgenerálás szabálylapja a Sheetben | régebben „skill set” néven is |
| Szárazfuttatás | `dry=1`: futás írás, feltöltés és e-mail nélkül | angolul: dry run |
| Felület | a poszt-előnézeti webes felület (`/posztok/`) | |
| Zárt / kibontott nézet | a poszt a „…több” előtt levágva / teljes egészében | |
